Bulk update SEO titles and meta descriptions for WordPress pages using a simple URL-based import.

== Description ==

SEO Meta Bulk Editor allows you to update SEO titles and meta descriptions for multiple WordPress pages from a single interface.

Instead of editing each page individually, simply paste your data, validate it, review the results, and update selected pages in bulk.

Current Version Features:

* Bulk URL-based import
* SEO Title updates
* Meta Description updates
* Validation before update
* Selective row updates
* Clear success and error notices
* Accessible admin interface

== Installation ==

1. Upload the plugin ZIP through Plugins → Add New.
2. Activate the plugin.
3. Open SEO Meta Bulk Editor from the WordPress admin menu.
4. Paste your data.
5. Validate.
6. Update selected rows.

== Frequently Asked Questions ==

= Which SEO plugin is supported? =

Version 1.0 currently supports Rank Math SEO fields.

= Does this modify page content? =

No. Only SEO metadata is updated.

= Can I preview before updating? =

Yes. Validation runs before updates are applied.
