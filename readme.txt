Bulk edit SEO titles and meta descriptions for WordPress pages by importing URLs, titles, and descriptions from a single interface.

== Description ==

SEO Meta Bulk Editor helps you quickly update SEO titles and meta descriptions for multiple WordPress pages without opening each page individually.

Simply prepare your data, paste it into the plugin, validate the entries, review the results, and update selected pages in bulk.

Designed for SEO professionals, agencies, freelancers, and website owners who regularly optimize large numbers of pages, the plugin reduces repetitive manual work while helping prevent update errors through built-in validation.

### Features

* Bulk update SEO titles and meta descriptions
* URL-based page matching
* Built-in validation before updating
* Preview validation results before applying changes
* Update only selected rows
* Clear success, warning, and error notices
* Lightweight and easy to use
* WordPress-native admin interface

### Compatibility

Version 1.0 currently supports Rank Math SEO metadata.

== Installation ==

1. Upload the plugin ZIP through **Plugins → Add New → Upload Plugin**.
2. Activate the plugin.
3. Open **SEO Meta Bulk Editor** from the WordPress admin menu.
4. Paste your SEO data.
5. Validate the imported rows.
6. Select the rows you want to update.
7. Apply the updates.

== Frequently Asked Questions ==

= Which SEO plugin is supported? =

Version 1.0 currently supports Rank Math SEO fields.

= Does this modify page content? =

No. The plugin only updates SEO metadata. Your page content remains unchanged.

= Can I preview before updating? =

Yes. Every import is validated before any changes are applied.

= Will this overwrite existing SEO metadata? =

Yes. Selected rows will replace the existing SEO title and meta description for the matched pages.
