# SEO Meta Bulk Editor

Bulk update SEO titles and meta descriptions for WordPress pages using a simple URL-based import.

## Overview

SEO Meta Bulk Editor is a lightweight WordPress plugin that helps you update SEO titles and meta descriptions for multiple pages in bulk.

Instead of editing each page individually, simply import your data, validate it, review the results, and apply updates with confidence.

Built for SEO professionals, agencies, freelancers, and website owners managing large websites.

---

## Features

- Bulk update SEO titles
- Bulk update meta descriptions
- URL-based page matching
- Built-in validation before updates
- Preview validation results
- Selective row updates
- Clear success, warning, and error notices
- Lightweight and easy to use
- WordPress-native admin interface

## Installation

### Install from ZIP

1. Download the latest plugin release.
2. Go to **Plugins → Add New → Upload Plugin**.
3. Upload the ZIP file.
4. Activate the plugin.
5. Open **SEO Meta Bulk Editor** from the WordPress admin menu.

### Install from Source

1. Clone this repository.
2. Copy the plugin folder into:

```
/wp-content/plugins/
```

3. Activate the plugin from **Plugins**.
4. Start using SEO Meta Bulk Editor.

---

## Usage

1. Prepare your SEO data.
2. Paste the data into the plugin.
3. Validate the imported rows.
4. Review the validation results.
5. Select the rows you want to update.
6. Apply the changes.
